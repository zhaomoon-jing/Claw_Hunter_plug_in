匹配度只按「技能 / 职位方向 / 薪资」计算，城市与公司不参与打分 —— 使用网站时请自行切换到目标城市。

① 简历档案

从简历 PDF/Word 里复制全文粘贴到下面，自动提取姓名、技能、期望薪资、目标职位（提取结果可手动增删）。

导出/导入 JSON 可与你本地 Python 端（claw-jobhunter）的 data/resume_profile.json 互通。

③ 使用方式

  1. 打开 Boss直聘 / 智联 / 拉勾 / 猎聘，搜索岗位并切换到目标城市（城市不影响打分）。
  2. 列表页每张卡片右上角显示 匹配分徽章，快速筛选高匹配岗位。
  3. 进入岗位详情页，JD 上方出现 匹配分析卡：精确分、命中/缺失技能、薪资对比、打招呼话术。
  4. 确认匹配后点 投递该岗位，二次确认后自动点击页面投递按钮，完成弹窗最后一步即可。
