爪猎 JobHunter

浏览器插件 · 简历 × 岗位实时匹配打分 · 人工复核后一键投递

v0.1.8 Boss直聘 智联招聘 拉勾网 猎聘

这是什么

在你自己已登录的浏览器里刷岗位时，插件自动读取岗位卡片和 JD，对照你的简历档案实时计算匹配分（技能 50 / 职位方向 30 / 薪资 20，总分 100；城市与公司不参与打分）。列表页看徽章快速筛选，详情页看精确匹配分析，确认后一键点击页面投递按钮（半自动，最后一步人工确认）。

核心功能

🎯 列表页打分徽章
每张岗位卡片右上角显示匹配分（绿/橙/灰），悬停看命中技能
📋 详情页匹配分析卡
精确分 + 技能/职位/薪资三条进度 + 命中/缺失技能 + 薪资对比
💬 打招呼话术
自动生成可编辑话术，一键复制
🚀 一键投递
确认后自动点击页面投递按钮，已投递岗位本地标记防重复
📥 简历档案一键导入
粘贴简历全文自动提取技能/期望薪资/目标职位，可手动增删
🔒 完全本地
档案只存浏览器本地，无任何外部请求，不读取无关信息

安装（Chrome / Edge）

  1. 打开扩展管理页：edge://extensions 或 chrome://extensions
  2. 打开右上角「开发者模式」
  3. 点「加载已解压的扩展程序」，选择本 zip 解压后的文件夹
  4. 工具栏出现 🐾 图标即安装成功

将本 zip 下载解压，即得到插件源码目录（内含 manifest.json）。

使用

  1. 点 🐾 → 打开配置页 → 粘贴简历全文 → 「从文本提取档案」→ 核对保存
  2. 打开 Boss/智联/拉勾/猎聘 搜索岗位（城市用网站自己的选择器切换）
  3. 列表页看卡片右上角匹配分徽章，详情页看匹配分析卡
  4. 匹配则点「投递该岗位」→ 二次确认 → 自动点击页面投递按钮，完成弹窗最后一步

评分规则（总分 100）

维度权重说明
技能匹配50JD 文本命中多少简历技能（按 min(技能数,10) 归一）
职位方向30岗位标题命中目标职位关键词
薪资匹配20岗位薪资区间与期望区间重叠程度
城市 / 公司—不参与打分（城市在网站上自行切换）
