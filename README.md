# 爪猎 · 简历匹配投递助手（浏览器扩展）

在你**自己**的浏览器里打开 **Boss直聘 / 智联 / 拉勾 / 猎聘**，自动给每个岗位打「匹配分」、给出命中技能、生成打招呼话术，人工复核后一键投递。
不再需要「复制 JD → 粘贴到脚本 → 再看面板」这种多此一举的流程——直接在招聘网站上看分、决定、投递。

## 为什么是浏览器扩展（而不是直接自动抓取）

招聘平台有反爬/风控，用脚本（Playwright 等）无人值守自动登录、抓取会被风控拦截（验证墙、IP 风险）。
而在**你自己的浏览器里**登录并正常浏览，页面 DOM 正常可读，风控不会触发。所以正确形态是：

- 你在浏览器里正常刷岗位；
- 扩展在列表页给每张卡片注入匹配分徽章，进详情页给精确匹配分析；
- 你复核，点「投递该岗位」时扩展帮你点页面的投递按钮，最后一步由你确认。

这是「半自动、人在环内」的安全方案，既便捷又不会被风控搞挂。

## 匹配打分（总分 100，纯规则、离线）

| 维度     | 权重 | 说明                                             |
| -------- | ---- | ------------------------------------------------ |
| 技能匹配 | 50   | JD 文本里命中多少简历技能（按 min(技能数,10) 归一） |
| 职位方向 | 30   | 标题命中目标职位关键词                           |
| 薪资匹配 | 20   | 岗位薪资区间与期望区间重叠程度                   |

**城市不打分**（你在网站上自行切换目标城市）；
**公司不打分**（没有目标公司，公司名里的技能词也不计入）。

## 架构

```
招聘页面 ──(读取岗位卡片 DOM)──▶  content/inject.js（通用注入）
                                   │  按 content/platforms.js 平台配置适配
                                   ▼
                     匹配分徽章 + 精确匹配分析卡 + 一键投递
简历档案 ── chrome.storage.local ──▶ 扩展直接使用
```

```
extension/
├── manifest.json         # MV3，匹配 zhipin/zhaopin/lagou/liepin
├── background.js         # service worker
├── assets/               # 图标
├── content/
│   ├── matcher.js        # 匹配引擎（技能50/职位30/薪资20，无城市无公司）
│   ├── platforms.js      # 四平台适配配置表（URL + 选择器 + 投递按钮关键词）
│   ├── inject.js         # 通用页面注入（列表徽章/详情匹配卡/一键投递）
│   └── content.css       # 注入样式
├── options/              # 配置页（简历档案管理）
├── popup/                # 工具栏弹窗
└── test/                 # 单测 + jsdom 集成测试 + mock 页
```

## 安装（Edge / Chrome）

1. 打开扩展管理页：
   - **Edge**：地址栏输入 `edge://extensions`，回车；
   - **Chrome**：`chrome://extensions`。
2. 右上角打开「开发人员模式」（Developer mode）。
3. 点「加载已解压的扩展程序」，选择本目录（`claw-jobhunter/extension/`）。
4. 看到「爪猎 · 简历匹配投递助手」即成功。

## 配置简历档案（只需一次）

1. 点工具栏 🐾 图标 → 「打开配置页」；
2. 从简历 PDF/Word 里复制全文，粘贴到「① 简历档案」→ 点「从文本提取档案」；
3. 核对/增删：姓名、目标职位关键词、技能、期望薪资（如 `17k-25k`）；
4. 点「保存档案」。

> 也可「导出 JSON / 导入 JSON」与你本地 Python 端 `claw-jobhunter/data/resume_profile.json` 互通。

## 使用

1. 打开 **Boss直聘 / 智联 / 拉勾 / 猎聘**，搜索岗位，**城市用网站自己的选择器切换**；
2. **列表页**：每张卡片右上角出现匹配分徽章（绿=高匹配，橙=达标，灰=低），悬停看命中技能；
3. **详情页**：JD 上方出现**精确匹配分析卡**：
   - 匹配分 + 技能/职位/薪资 三条进度；
   - 命中技能（绿）、「JD提到·简历暂无」技能（灰，可判断要不要补学）；
   - 岗位薪资 vs 期望薪资对比；
   - 打招呼话术（可编辑）+「复制话术」；
   - 「投递该岗位」→ 二次确认 → 自动点击页面投递按钮（半自动，弹窗最后一步你手动完成）；
4. 已投递岗位右下角出现「✓ 已投递」标记，避免重复。

## 调试（徽章/匹配卡不显示时）

1. 在问题页面按 `F12` → Console，看红色报错；
2. 常见：`extension context invalidated` → 在扩展管理页点 ⟳ 重载插件；
3. 若页面结构改版（class 变了），右键检查元素，把岗位卡片/JD 区块的 class 名查看，
   在 `content/platforms.js` 对应平台的 `cards / cardFields / detailFields / anchors` 数组里加一个 fallback 选择器即可；
4. 想要插件更新后立即生效：扩展管理页点 ⟳ 重载，然后刷新招聘页面。

## 隐私与限制

- 简历档案只存本地 `chrome.storage.local`，无任何外部请求；
- 一键投递只点击页面已有按钮，不替你发送消息；
- 各平台前端改版时选择器可能失效（见「调试」节），这是此类扩展的固有限制；
- 已投递记录按岗位 URL 本地去重。
